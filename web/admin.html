Publication de la carte publique (GitHub Pages)

La carte publique hébergée sur GitHub Pages est une copie statique des données : couches de référence et saisies validées. Elle ne contient ni comptes, ni photos, ni saisies en attente.

Pour la mettre à jour après des validations, lancez sur le poste serveur, dans le dossier du projet :

powershell -ExecutionPolicy Bypass -File scripts\publier.ps1

Le script exporte les données publiques depuis PostGIS, les enregistre dans le dépôt GitHub, et GitHub met le site à jour en une à deux minutes.
